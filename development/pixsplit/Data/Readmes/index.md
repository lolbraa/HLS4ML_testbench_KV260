# Pixsplit - Splitting Merged Pixel Clusters

A [lightning](https://www.pytorchlightning.ai/index.html) based framework used to train neural networks to determine the locations of particles in merged clusters in the ATLAS inner detetcor. This package builds on and refers to work done in both the original pixel cluster splitting [repository](https://gitlab.cern.ch/Atlas-Inner-Tracking/pixel-NN), and the subsequent mixture density network [repository](https://gitlab.cern.ch/Atlas-Inner-Tracking/pixel-MDN).
